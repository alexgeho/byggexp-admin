## Общие правила (замечания владельца, применять на всю админку)
- Наведение (18.11): всё, на что можно нажать, меняется под курсором — кнопки (в том числе вторичные и в нижних панелях), галочки, ссылки, строки и карточки, по которым кликают, плашки броней. Вторичная кнопка: фон чуть темнее + рамка темнее; галочка: синяя рамка; плашка: приподнимается (тень). Новый кликабельный элемент без состояния :hover — баг. Исключение по слову владельца: ячейки таблицы часов цвет под курсором не меняют (правило трёх цветов), у редактируемой ячейки подчёркивается число.
- Обязательные поля (18.11): в форме обязательны только самые важные данные — то, без чего действие невозможно (приглашение — только E-post). Всё остальное необязательное: его заполнит сам приглашённый или дополнят позже. Звёздочка стоит только у таких полей; перед тем как сделать поле обязательным, спросить себя «без этого действие правда невозможно?».
- Таблицы с выделением строк (17.11): пока строки выбраны, слева остаётся только выбранный фильтр статуса (остальные скрыты), поиска нет — на его месте кнопка «Ta bort (N)» того же размера (180×40), остальные действия по выбранным — слева от неё; сразу за ним — «× Rensa markering» без рамки (текстовая кнопка, снимает выделение); итог по выбранным (в рамке как у secondary-кнопки, без заливки) — справа, вплотную к действиям. Сняли выделение — поиск и все фильтры возвращаются. Узкое окно (18.11): ничего не наезжает — что не помещается в строку, переносится на вторую строку (кнопки справа), итог не сжимается. Общий компонент `AdminTable`, действует во всех таблицах.
- Период «свои даты» (17.11): в русском интерфейсе называется «Свой период» (не «Произвольно»); sv «Anpassad».
- Выпадающий список в узком поле (17.11): список шириной по самому длинному пункту, названия не обрезаются многоточием; номер и название артикула через пробел, без длинного тире («5 Timarbete VVS-montör») — Faktura и Offert.
- Акцент ведёт по шагам (17.11): синяя полоса слева 4px + тень (0 10px 30px, 13%) стоит только на одной карточке — на следующем шаге — и смещается вниз по мере заполнения (заказ → Mål: цель → «Dela upp» → первый незавершённый этап; все этапы готовы — акцента нет). Остальные карточки — рамка без тени.
- Иерархия внимания (17.11): главный блок вкладки (заказ → Mål: цель и этапы) заметнее шапки заказа и вкладок над ним — белая карточка с рамкой #d3dde6 и тенью (0 10px 30px, 13%), у карточки цели синяя полоса слева 4px, крупный тёмный текст (цель 20px/700, рамка поля #b9c7d4), главное действие — синяя кнопка. Шапка и вкладки — второстепенные, их не усиливать.
- Текст вводится только в светлое поле (17.11): тёмных плашек с вводом текста нет — белая карточка, поле 40px с рамкой #d3dde6 (заказ → Mål: шапка цели). В тёмной теме — тёмное.
- Подсказки под полями (17.11): без расшифровок ролей вроде «Chef = orderansvarig / ägare» — одна короткая фраза («0 = ingen eskalering.»).

## Planering — что нельзя ломать (сводка на 2026-11-17)

Короткий список для проверки перед любой правкой Planering. Подробности и слова владельца — в «Общих правилах» выше (строки с пометками 12.11 и 17.11). Нарушение пункта — баг.

**Вид**

1. Vecka / 2 veckor — календарь как Google (часы слева), Månad / Anpassad — таймлайн по людям. Колонка людей одна и та же во всех видах: цветной чекбокс + имя.
2. Клик по брони открывает ордер («Ny bokning» в режиме правки). Клик или протяжка по свободному месту — «Ny bokning» на эти дни и время.

**Бронь и ордер**

3. Бронь всегда стоит на ордере: существующий ордер выбран или написано описание (оно становится названием нового ордера). В «+ Tilldela» и «Bemanna lag» ордер обязателен, поле не очищается. Брони без ордера не создаются нигде.
4. «Ny bokning»: в Personal никто не выбран — бронь ставится на того, кто создаёт ордер.

**Перенос**
