# Таблица смен — правила

Страница: Arbetspass → таблица часов (сотрудники × дни).
Не совпадает с этим файлом — баг.

## Цвета — только 3

| Цвет | Когда |
|---|---|
| **Фиолетовый** | запланированные часы, всё по плану |
| **Кремовый** | отклонение от плана — **или** человека не было вообще (ни GPS, ни вручную) |
| **Серый** | выходные |

Белого нет. Зелёного нет. Других цветов нет.

## Что в ячейке

- **Крупное число** — часы по плану.
- **Мелкие цифры под ним** — факт: зелёные = GPS, оранжевые = рабочий ввёл сам.
- **«–»** в кремовой ячейке — человека не было.

## Отклонение

С планом сравниваются **только ручные часы** рабочего. GPS сам по себе отклонением не считается.
Цифра в кружке у имени — сколько дней с отклонением.

## Итоги

- Справа — сумма по сотруднику, снизу — по дню.
- Дни, когда человека не было, в итог не идут.
- План уже без обеда — обед второй раз не вычитаем.

## Редактирование

- Клик по ячейке → число → Enter. Esc — отмена.
- Вписанное число — окончательное, даже если совпадает с планом.
- Клик по оранжевой цифре (ручные часы) — она становится плановой.
- «Kopiera → nästa period» переносит только вписанное админом, не сам график.
