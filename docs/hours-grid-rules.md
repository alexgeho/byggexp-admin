# Таблица смен — правила

Страница: Arbetspass → таблица часов (сотрудники × дни).
Не совпадает с этим файлом — баг.

## Цвета — только 3

| Цвет | Когда |
|---|---|
| **Фиолетовый** | все будние дни (план) |
| **Кремовый** | отклонение часов от плана — **или** человека не было вообще (ни GPS, ни вручную) |
| **Серый** | все выходные — **даже если человек работал** |

Белого нет. Зелёного нет. Красного нет. Других цветов нет. Наведение мышью цвет не меняет.

Выбранный сотрудник (галочка, 17.11): его ячейки плана и выходных — голубые, как ячейка имени; кремовые остаются кремовыми.

Столбцы дней — 54px, как в ролике (меняются только зумом). Пустого столбца перед итогом нет: лишняя ширина уходит в колонки имени и итога (17.11).

Правила закреплены тестом `src/features/shifts/hoursDesignSystem.test.js`.

## Что в ячейке

- **Крупное число** — часы по плану, 16px (как имя сотрудника, не больше).
- **Мелкие цифры под ним** (13.5px) — факт: зелёные = GPS, оранжевые = рабочий ввёл сам. В ячейке всегда все три часа (12.11, для видео): в плановый день до сегодня включительно нет GPS — зелёный «–», нет ручных — оранжевый «–».
- **«–»** в кремовой ячейке — человека не было.

## Отклонение

С планом сравниваются **только ручные часы** рабочего. GPS сам по себе отклонением не считается.
Цифра в кружке у имени — сколько дней с отклонением.

## План по нескольким заказам (17.11)

- У человека в день один рабочий день: в «Alla order» план по расписанию не складывается по заказам (4 открытых заказа = 8 ч, не 32).
- План, вписанный админом вручную по разным заказам, складывается и заменяет план по расписанию.
- Больше 24 ч в ячейке не бывает.

## Нижняя панель (17.11)

- Одна строка: «N anställda · часы» | Timmar + Fyll, Rensa, Skicka till lön, Förbered fakturautkast. Экспорта в панели нет — он в меню Exportera.

## Итоги

- Справа — сумма по сотруднику, снизу — по дню.
- Дни, когда человека не было, в итог не идут.
- План уже без обеда — обед второй раз не вычитаем.

## Редактирование
коро
- Клик по ячейке → число → Enter. Esc — отмена.
- Вписанное число — окончательное, даже если совпадает с планом.
- Клик по оранжевой цифре (ручные часы) — она становится плановой.
- «Kopiera → nästa period» переносит только вписанное админом, не сам график.
