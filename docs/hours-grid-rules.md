# Таблица смен — как она должна работать

Страница: Arbetspass → таблица часов (сотрудники × дни).
Если таблица ведёт себя не так, как здесь написано, — это баг.

---

## Что видно в ячейке

Каждая ячейка — один сотрудник в один день. В ней может быть:

- **Крупное число** — часы, которые идут в итог.
- **Мелкие цифры под ним** — что реально было: зелёная = по GPS, оранжевая = рабочий ввёл сам.
- **Оранжевый прочерк «–»** — человек должен был работать, но не пришёл (или был в отпуске/на больничном).
- **Ничего** — работы не было и не планировалось. Ячейка просто пустая и белая.

Больше никаких значков. Точек, нулей и серых прочерков быть не должно.

---

## Вид «Planerat» (по плану)

| Ситуация | Что показываем | Идёт в итог |
|---|---|---|
| Сегодня или будущий день по графику | часы по плану (напр. **8**) | да |
| Прошедший день по графику, человек работал | **8**, под ним GPS и/или ручные часы | да |
| Прошедший день по графику, ни GPS, ни ручных часов | оранжевый **–** | нет |
| Отпуск / больничный (Frånvaro) | оранжевый **–** | нет |
| Админ сам вписал число | это число | да |
| Работал вне графика (напр. в субботу) | крупного числа нет, только мелкие цифры GPS/ручных | нет |
| Ничего нет | пусто | нет |

Часы по плану уже **без обеда**. Обед второй раз не вычитаем.

---

## Цвет ячейки

- **Сиреневый** — всё по плану.
- **Зелёный** — рабочий вписал больше, чем по плану.
- **Оранжевый** — вписал меньше / не пришёл.

Сравниваем с планом **только ручные часы** рабочего. GPS никогда не бывает ровно 8, поэтому сам по себе цвет не меняет.
Цифра в кружке рядом с именем — сколько дней с расхождением.

---

## Невозможные часы

Больше 16 часов за день — это ошибка (смена не закрыта, опечатка).
Такие часы **не показываем и не считаем**, вместо них — красная точка, при наведении видно исходное число.

---

## Вид «GPS» и «Manuell»

То же самое, только крупное число — часы по GPS (или ручные) минус обед, а план — мелко под ним.

---

## Итоги

- **Справа** — сумма по сотруднику, **снизу** — сумма по дню. Считаем только то, что «идёт в итог».
- Общий итог в углу = сумма всех строк = сумма всех дней.

---

## Имена

«Unknown» быть не должно. Если имени нет — показываем e-mail, если нет и его — телефон.

---

## Выходные

План на субботу/воскресенье есть, только если он стоит в графике проекта. С будних дней не копируем.

---

## Редактирование

- Нажал на ячейку → вписал число → Enter. Esc — отмена.
- Вписанное число — окончательное, даже если совпадает с планом.
- Ручные часы рабочего админ не меняет, но может нажать на оранжевую цифру — она станет плановой.
- «Kopiera → nästa period» переносит только то, что вписал админ, а не сам график.
