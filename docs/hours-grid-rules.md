# Правила таблицы смен (Arbetspass → Timmar)

Единственный источник правды для `src/features/shifts/HoursPage.jsx`.
Любое изменение грида — сначала сверить с этим файлом. Не совпадает → баг.

## 1. Данные ячейки (сотрудник × день)

| Поле | Откуда | Примечание |
|---|---|---|
| `planned` | график проекта (backend) | **уже без обеда** — во FE обед больше не вычитать |
| `edited` | админ ввёл значение | введённое число — финальное, даже если = графику |
| `actual` | GPS | |
| `manual` | рабочий ввёл сам | |
| `absent` | одобренный Frånvaro | |

## 2. Что показывает ячейка — вид «Planerat»

Проверять строго по порядку, первое совпадение побеждает:

| # | Условие | Большое число | Под ним | Фон | В сумму |
|---|---|---|---|---|---|
| 1 | `absent` | `–` | — | янтарный | 0 |
| 2 | `edited` | введённое | GPS · Manual | лаванда | да |
| 3 | план есть, день ≥ сегодня | план | — | лаванда | да |
| 4 | план есть, прошлое, есть GPS или Manual | план | GPS · Manual | лаванда / отклонение | да |
| 5 | план есть, прошлое, нет GPS и Manual | `–` (не пришёл) | — | янтарный | 0 |
| 6 | плана нет, но есть GPS/Manual (выходной, внеплановая работа) | пусто | GPS · Manual | белый | 0 |
| 7 | ничего нет | пусто | — | белый | 0 |

## 3. Символы — только два

- **Число** — часы.
- **`–` янтарный** — должен был работать и не пришёл / Frånvaro.
- Запрещено: `·`, `0`, серый `–`, пустая цветная заливка. Нет данных → пустая белая ячейка.

## 4. Под-строка (GPS · Manual)

- GPS — зелёный, Manual — оранжевый (клик = принять как план).
- Значение `0` или пустое — не показывать.
- Показывать только корректные значения (см. §6).

## 5. Цвет отклонения

- Сравнивается **только Manual** с планом (GPS всегда «плавает» — сам по себе не флагает).
- |Manual − план| ≤ grace → лаванда. Больше → зелёный, меньше → янтарный.
- Счётчик-бейдж у имени = число таких дней.

## 6. Санити-проверки (данные, которым нельзя верить)

- GPS/Manual > 16 ч за день — смена не закрыта / ошибка. Не показывать как часы; ячейка с красной точкой-предупреждением, в суммы не идёт.
- Один день = одно значение на сотрудника в рамках выбранного проекта.

## 7. Строки и итоги

- Имя никогда не «Unknown»: имя → e-mail → телефон.
- Сотрудник без единой ячейки по правилам 2–6 за период — строку не показывать.
- **Totalt** (строка) = сумма ячеек «в сумму: да».
- **Dagssumma** (колонка) = то же по дню. Totalt снизу-справа = Σ строк = Σ дней.

## 8. Выходные

- Сб/Вс — план только если он есть в графике проекта. Не заполнять копированием с будней.
- Колонка выходного — серый фон заголовка, ячейки по общим правилам.

## 9. Виды «GPS» и «Manuell»

Те же правила, но большое число = GPS (или Manual) за вычетом обеда (если день ≥ порога),
под ним — план мелко. Нет значения → пусто (не `·`, не `0`). No-show `–` — так же, как в §2.

## 10. Редактирование

- Клик по ячейке (кроме Frånvaro) → ввод. Enter/blur — сохранить, Esc — отмена.
- Введённое значение = финальное (`edited`), показывается по правилу 2.
- «Kopiera → nästa period» копирует только `edited`, не базовый график.
