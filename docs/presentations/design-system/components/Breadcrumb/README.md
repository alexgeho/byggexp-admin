# Breadcrumb

Plain-text path to where a step is done, so the reader knows which app and which menu.

- First and last item bold, middle items `muted`, arrows `›` in `blue`, `&nbsp;` around arrows.
- On a step slide it follows `Steg N&nbsp;·&nbsp;` (blue, uppercase, letter-spaced) and sits 12px above the heading.
- Never a pill, chip or button.
