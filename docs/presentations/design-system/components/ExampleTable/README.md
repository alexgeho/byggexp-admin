# ExampleTable

A real example of what the system produces (an export file, a payslip basis), one person per table.

- Three lines only: 2px `ink` on top and bottom, 1px `ink` under the header. No zebra, no row lines.
- Numbers right-aligned, `tabular-nums`, one precision per column (2 decimals, Swedish comma). Label column on the right in `muted` DM Sans.
- A bold "Summa" row closes the table; it must match the number shown in the app.
- Person line above the table: name bold, `anstid · månad` muted.
