# Презентация «Lön enligt Byggavtalet»

Презентация модуля зарплаты по Byggavtalet для клиентов. Две версии, обе — слайд-деки на claude.ai:

| Язык | Открыть | Исходники |
|---|---|---|
| Шведский (для клиента) | https://claude.ai/artifact/PdKaUrZKrR9R4xAccFK5Bf | [`sv/`](sv) |
| Русский (для нас) | https://claude.ai/artifact/58yNpCxHi9JqYdgL92h1EZ | [`ru/`](ru) |

Ссылки приватные: чтобы открыть, владелец должен поделиться ими через кнопку Share на claude.ai.

## Устройство

- `deck.json` — порядок слайдов, разделы, шрифты.
- `slides/<id>.html` — один слайд, холст 1920×1080. В `<aside>` — текст для выступающего (на русском в обеих версиях).
- Картинки (`/_blob/...`) хранятся на claude.ai, в репозитории их нет.

## Как править вместе с Claude

1. Открыть Claude Code в этом репозитории.
2. Попросить, например: «в шведской презентации docs/presentations/lon-byggavtalet обнови слайд avtal и опубликуй в https://claude.ai/artifact/PdKaUrZKrR9R4xAccFK5Bf».
3. Claude сначала читает живую версию на claude.ai, вносит правку и публикует. Затем обновить файлы здесь и закоммитить, чтобы репозиторий совпадал с опубликованной версией.

Комментарии на слайдах claude.ai тоже доходят до Claude, если отправить их кнопкой «Send to Claude».
