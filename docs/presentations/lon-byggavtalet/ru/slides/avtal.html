Всегда по действующему договору

Версии с датами

Каждый период договора — отдельная версия. Каждый рабочий день считается по версии, действовавшей в этот день.

Закрытая история

Опубликованную версию изменить нельзя. Прошлые периоды никогда не пересчитываются задним числом.

Обновляем мы

Когда подписан новый Byggavtal, ByggExp вносит ставки с указанием источника. Вам ничего делать не нужно.

Ответ на главный запрос клиента «чтобы всё обновлялось по требованиям Byggnads». Честно: у Byggnads нет API, поэтому новые цифры вносим мы по тексту договора, с указанием источника, и публикуем с даты начала. История не меняется задним числом.
