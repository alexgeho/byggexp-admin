Как идут данные

1

Отчёт

Рабочий отмечает часы, тип часов, поездку и суточные в приложении.

2

Аттестация

Прораб подтверждает часы за день.

3

Основание

ByggExp считает каждый день по Byggavtalet.

4

Зарплатная программа

Импорт одним файлом. Программа считает налог и платит зарплату.

Четыре шага: рабочий отчитывается в приложении (часы, тип часов, поездка, суточные), прораб аттестует, ByggExp считает каждый день по версии договора, файл импортируется в зарплатную программу клиента.
