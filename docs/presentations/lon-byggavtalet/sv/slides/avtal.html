En publicerad version kan inte ändras. Gamla perioder räknas aldrig om i efterhand.

Lönehöjning i maj: förslag på ny timlön för varje anställd

Ответ на главный запрос клиента «чтобы всё обновлялось по требованиям Byggnads». ByggExp каждую неделю проверяет сайт Byggnads, сам скачивает новый Byggavtalet и с помощью ИИ создаёт версию договора по каждому году, с цитатами из источника. Публикует её наш сотрудник после проверки цифр — это защита от ошибки ИИ в зарплате. В мае, когда растут ставки, компания получает готовое предложение новой ставки по каждому сотруднику и применяет его одной кнопкой. Налоговые таблицы Skatteverket тоже загружаются автоматически.
