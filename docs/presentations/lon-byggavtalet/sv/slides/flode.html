Så går flödet

1

Rapport

Arbetaren rapporterar timmar, timtyp, resa och traktamente i appen.

2

Attest

Arbetsledaren godkänner dagens timmar.

3

Löneunderlag

ByggExp räknar varje dag enligt Byggavtalet.

4

Lönesystemet

Import med en fil. Ert lönesystem räknar skatt och betalar lön.

Четыре шага: рабочий отчитывается в приложении (часы, тип часов, поездка, суточные), прораб аттестует, ByggExp считает каждый день по версии договора, файл импортируется в зарплатную программу клиента.
